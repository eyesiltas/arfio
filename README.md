# Arfio

**Yapay zekâ destekli nicel veri analizi** · *AI-assisted quantitative data analysis*

Arfio, nicel araştırma verilerini analiz eden ve sonuçları APA biçiminde tablolar, grafikler ve Türkçe/İngilizce akademik bulgu paragraflarına dönüştüren bir Windows masaüstü uygulamasıdır. Adını Türk matematikçi **Cahit Arf**'ten (1910–1997) almaktadır. Tüm hesaplar ve isteğe bağlı dil modeli bilgisayarınızda çalışır; verileriniz internete gönderilmez.

Bu depo yalnızca **kurulum dosyalarının dağıtımı** içindir. Ayrıntılı bilgi ve kullanma kılavuzu: <https://arfio.erkanyesiltas.com>

## İndir

En güncel sürüm: **[Releases](https://github.com/eyesiltas/arfio/releases/latest)** sayfasındaki `Arfio-<sürüm>-Kurulum.exe` dosyası.

- Windows 10/11, 64 bit; 16 GB RAM önerilir. Kurulum yönetici izni istemez.
- Kurulum dosyası dijital olarak imzalanmadığı için Windows “Windows bilgisayarınızı korudu” uyarısı gösterebilir: **Ek bilgi → Yine de çalıştır**.
- Dosyanın bütünlüğünü sürüm sayfasındaki SHA-256 özetiyle doğrulayabilirsiniz (PowerShell: `Get-FileHash .\Arfio-0.10.0-Kurulum.exe`).
- Kurulu Arfio yeni sürümleri kendisi bildirir ve tek tıkla günceller (Ayarlar → Güncellemeleri otomatik denetle).

## Atıf

Arfio ücretsiz dağıtılmaktadır. Arfio ile yapılan analizlerin kullanıldığı çalışmalarda (makale, tez, bildiri, rapor vb.) uygulamaya atıf yapılması gerekmektedir. Önerilen atıf (APA 7):

> Yeşiltaş, E. (2026). *Arfio: Yapay zekâ destekli nicel veri analizi uygulaması* (Sürüm 0.10.0) [Bilgisayar yazılımı]. https://arfio.erkanyesiltas.com

**English.** Arfio is a free Windows desktop application that analyses quantitative research data and reports results as APA tables, charts and academic findings paragraphs in Turkish or English. All calculations run locally. Download the installer from [Releases](https://github.com/eyesiltas/arfio/releases/latest). Studies using Arfio must cite it (see above; English citation is available in the application's About window).
