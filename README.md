# Arfio

**Yapay zekâ destekli nicel veri analizi** · *AI-assisted quantitative data analysis*

Arfio, nicel araştırma verilerini analiz eden ve sonuçları APA biçiminde tablolar, grafikler ve Türkçe/İngilizce akademik bulgu paragraflarına dönüştüren bir masaüstü uygulamasıdır (Windows ve Linux). Adını Türk matematikçi **Cahit Arf**'ten (1910–1997) almaktadır. Tüm hesaplar ve isteğe bağlı dil modeli bilgisayarınızda çalışır; verileriniz internete gönderilmez.

Bu depo yalnızca **kurulum dosyalarının dağıtımı** içindir. Ayrıntılı bilgi ve kullanma kılavuzu: <https://arfio.erkanyesiltas.com>

## İndir

En güncel sürüm: **[Releases](https://github.com/eyesiltas/arfio/releases/latest)** sayfası.

**Windows** — `Arfio-<sürüm>-Kurulum.exe`
- Windows 10/11, 64 bit; 16 GB RAM önerilir. Kurulum yönetici izni istemez.
- Kurulum dosyası dijital olarak imzalanmadığı için Windows “Windows bilgisayarınızı korudu” uyarısı gösterebilir: **Ek bilgi → Yine de çalıştır**.

**Linux** — `arfio_<sürüm>_amd64.deb`
- Ubuntu 22.04, Debian 12 ve üzeri (Linux Mint, Pardus vb. Debian tabanlı dağıtımlar), 64 bit.
- Kurulum: `sudo apt install ./arfio_<sürüm>_amd64.deb` (gerekli kitaplıklar otomatik kurulur). Dil modeli ilk açılışta **Model ayarları → Modeli indir** ile indirilir.

Her iki platformda dosyaların bütünlüğünü sürüm sayfasındaki `SHA256SUMS.txt` ile doğrulayabilirsiniz. Kurulu Arfio yeni sürümleri kendisi bildirir ve tek tıkla günceller (Ayarlar → Güncellemeleri otomatik denetle).

## Atıf

Arfio ücretsiz dağıtılmaktadır. Arfio ile yapılan analizlerin kullanıldığı çalışmalarda (makale, tez, bildiri, rapor vb.) uygulamaya atıf yapılması gerekmektedir. Önerilen atıf (APA 7):

> Yeşiltaş, E. (2026). *Arfio: Yapay zekâ destekli nicel veri analizi uygulaması* (Sürüm 0.10.1) [Bilgisayar yazılımı]. https://arfio.erkanyesiltas.com

---

**English.** Arfio is a free desktop application for Windows and Linux that analyses quantitative research data and reports results as APA tables, charts and academic findings paragraphs in Turkish or English. All calculations run locally. Download the Windows installer or the Linux `.deb` package from [Releases](https://github.com/eyesiltas/arfio/releases/latest). Studies using Arfio must cite it (see above; English citation is available in the application's About window).
